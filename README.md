# AR Anatomy Textbook — Интерактивный AR-атлас анатомии человека

Мобильное приложение дополненной реальности (Augmented Reality) для наглядного изучения анатомии человека. Разработано на базе **Unity 2022.3 LTS** и **AR Foundation (ARCore)** для устройств под управлением Android.

---

## Ключевые возможности

**12 высокодетализированных 3D-моделей органов:**
  1. **Сердце человека** (с процедурной систоло-диастолической пульсацией и регулировкой частоты сердечных сокращений BPM).
  2. **Головной мозг** (лобная, теменная, затылочная, височная доли, мозжечок и ствол мозга с реалистичными бороздами и извилинами).
  3. **Легкие и трахея** (правое и левое легкое, трахея и бронхиальное дерево).
  4. **Печень** (правая и левая доли, воротная вена, нижняя полая вена и желчный пузырь).
  5. **Почки и мочевыделительная система** (парные почки, корковое/мозговое вещество, почечные лоханки, мочеточники и сосуды).
  6. **Желудочно-кишечный тракт (ЖКТ)** (дно, тело и пилорический отдел желудка).
  7. **Поджелудочная железа** (головка, тело, хвост, панкреатический проток).
  8. **Селезенка** (пульпа, ворота селезенки и сосудистая сеть).
  9. **Мочевой пузырь** (верхушка, тело, дно и мочепузырный треугольник).
  10. **Желчный пузырь** (дно, шейка, пузырный проток болотного анатомического оттенка).
  11. **Щитовидная железа** (доли, перешеек и паращитовидные железы).
  12. **Матка и придатки** (тело матки, миометрий, шейка, маточные трубы и яичники).

- **Интерактивность и медицинская информация:**
  - При тапе по любой детали органа отображается русское название, международный латинский термин (*Nomina Anatomica*), системная принадлежность, анатомическая функция и **клиническое значение** (патологии, значение в хирургии и терапии).
  - 3D Billboard-выноски со стрелками в дополненной реальности, привязанные к точкам интереса.
- **Взрыв-схема (Exploded View):** плавный разлет составных долей и сосудов органа от центра для изучения внутреннего строения.
- **Манипуляции в AR:**
  - Вращение модели в **любых плоскостях** (Yaw + Pitch) одним пальцем относительно угла обзора камеры.
  - Масштабирование (Pinch-to-zoom) двумя пальцами.
- **SLAM-прицел (Reticle):** умный адаптивный маркер наведения, точно привязывающий орган к плоскости стола или пола.
- **Режим X-Ray (Рентген):** полупрозрачность окружающих тканей с сохранением полной непрозрачности выбранного анатомического сегмента.

## Технологический стек

- **Движок:** Unity 2022.3.30f1 LTS
- **Графический пайплайн:** Built-in Render Pipeline (оптимизированные мобильные шейдеры)
- **AR Фреймворк:** AR Foundation 5.1.5 + Google ARCore XR Plug-in
- **Система ввода:** New Input System + Legacy Input Fallback (Universal Input Helper)
- **UI:** Unity UI (uGUI) + TextMeshPro (кириллическая типографика SDF)
- **Язык программирования:** C# (.NET Standard 2.1)
- **Целевая платформа:** Android 7.0 (Nougat, API Level 24) и выше с поддержкой Google Play Services for AR (ARCore)

## Установка готового APK

Готовый установочный пакет размещен в разделе **[Releases](../../releases)**:

1. Скачайте файл **`AR-anatomy-textbook.apk`** на ваше Android-устройство.
2. Убедитесь, что на устройстве установлены актуальные **Google Play Services for AR** (Сервисы Google Play для AR).
3. Разрешите установку из неизвестных источников в настройках безопасности Android.
4. Установите приложение, предоставьте доступ к камере при первом запуске и наведите камеру на горизонтальную поверхность (стол или пол).

---

## Сборка из исходного кода в Unity

1. Установите **Unity Hub** и версию редактора **Unity 2022.3.30f1** с модулем **Android Build Support** (включая Android SDK, NDK и OpenJDK).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Andruschka77/AR-anatomy-textbook.git
   ```
3. Откройте проект через Unity Hub (выберите папку с проектом).
4. Откройте главную сцену:
   `Assets/_Project/Scenes/AR_Anatomy_MainScene.unity`
5. В верхнем меню Unity выберите:
   - **`Anatomy AR -> Setup Complete Project & Scene`** — для проверки и перегенерации всех ScriptableObjects и префабов.
   - **`Anatomy AR -> Build Android APK`** — для автоматической компиляции готового APK-файла.

## Структура проекта в репозитории

```
AR_Anatomy/
├── Assets/
│   ├── _Project/
│   │   ├── Materials/         # Материалы PBR и X-Ray шейдеров
│   │   ├── Models/            # 3D-модели (OBJ, GLB, текстуры)
│   │   ├── Prefabs/           # Настроенные префабы органов и UI
│   │   ├── Scenes/            # Сцена AR_Anatomy_MainScene.unity
│   │   ├── ScriptableObjects/ # База данных анатомических описаний и фактов
│   │   └── Scripts/           # Исходный код C# (AR, Controllers, UI, Data)
│   └── TextMesh Pro/          # Шрифты и SDF-атласы с поддержкой кириллицы
├── Packages/
│   └── manifest.json          # Зависимости проекта (AR Foundation, TMP, Input System)
├── ProjectSettings/           # Настройки проекта, физики, тегов, слоев и графики
├── .gitignore                 # Исключение кэшей Library/, Temp/ и временных файлов
└── README.md                  # Документация проекта
```
